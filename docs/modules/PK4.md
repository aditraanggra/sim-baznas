# Modul PK4: Keuangan

Rilis P4. Cakupan dari PRD 8 dan kriteria selesai PRD 14.2.

## Cakupan

- Prioritas A (bisa mulai tanpa format): `fin_reports` + `fin_documents` (unggah PDF/Excel, metadata jenis/periode, status Draft/Final/Diaudit, kunci Final, buka kunci Admin dengan alasan, riwayat versi).
- Prioritas B (setelah Q1): `fin_templates`, `fin_template_rows`, `fin_values`; input/impor; subtotal/rumus memakai mesin tabel pohon; bandingkan periode; ekspor.
- Ditunda (P-D): FR-K-07 konsistensi laporan vs realisasi.

## Kriteria selesai (PRD 14.2)

Sesuai format yang dikirim: template, input atau impor, status dan penguncian, unggah dokumen, bandingkan periode, ekspor.

## Uji wajib

- BR-06 (kunci Final hanya Admin dengan alasan) pada laporan.
- Riwayat versi dokumen.

## Gerbang rilis P4

Satu laporan keuangan nyata tampil sesuai format dan disetujui Keuangan.
